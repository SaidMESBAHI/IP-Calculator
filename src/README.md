# 🖥️ IP Subnet Calculator

Un outil pour calculer les informations d'un sous-réseau IP avec interface graphique (Tkinter).

## 📋 Fonctionnalités
- Calcul de l'adresse réseau et de broadcast
- Détermination du nombre d'hôtes disponibles
- Conversion automatique entre masque de sous-réseau et notation CIDR
- Validation des entrées utilisateur
